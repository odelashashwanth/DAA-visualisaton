What is Insertion Sort?

Insertion Sort is a simple sorting algorithm that builds the sorted array one element at a time. It picks one element (called the Key), compares it with previous elements, shifts larger elements to the right, and inserts the key into its correct position.

Real Life Example

Imagine arranging playing cards in your hand. Every time you pick a new card, you insert it into the correct position. That is exactly how Insertion Sort works.

Algorithm Steps

  1. Select the Key element.
  2. Compare with previous elements.
  3. Shift larger elements right.
  4. Insert the Key.
  5. Repeat until sorted.

✅ Advantages

  • Easy to understand and implement.
  • Works efficiently for small datasets.
  • Stable Sorting Algorithm.
  • Requires only O(1) extra memory.
  • Good for nearly sorted arrays.

❌ Disadvantages

  • Slow for large datasets.
  • Worst Case Time Complexity O(n²).
  • Performs many shifts.
  • Not suitable for Big Data.
  • Less efficient than Merge Sort or Quick Sort.
