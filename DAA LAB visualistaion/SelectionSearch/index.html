HOW IT WORKS

Selection Sort Logic

01

Find Minimum

Search the unsorted portion of the array to find the smallest element.

02

Select Element

Keep track of the position of the minimum element found.

03

Swap

Exchange the minimum element with the first unsorted element.

04

Repeat

Continue until every element is placed in sorted order.

PERFORMANCE

Time & Space Complexity

BEST CASE O(n²)

Comparisons remain quadratic even when the array is sorted.

AVERAGE CASE O(n²)

The algorithm performs quadratic comparisons on average.

WORST CASE O(n²)

Maximum number of comparisons occurs in the worst case.

SPACE O(1)

Selection Sort works in-place using constant extra space.
