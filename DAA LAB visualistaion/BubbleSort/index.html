PERFORMANCE ANALYSIS

Complexity

BEST CASE O(n)

Occurs when the array is already sorted and no swaps are required.

AVERAGE CASE O(n²)

Multiple comparisons and swaps may be required.

WORST CASE O(n²)

Occurs when the array is arranged in reverse order.

SPACE O(1)

Bubble Sort works in-place and requires constant extra memory.
