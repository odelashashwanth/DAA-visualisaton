How Dynamic Programming Works

Instead of solving the same problem repeatedly, Dynamic Programming stores the result of smaller subproblems and reuses them.

dp[i] = min(dp[i], dp[i - coin] + 1)
1 Initialize dp[0] = 0.
2 Set all other values to infinity.
3 Try every coin for every amount.
4 Keep the minimum number of coins.
5 Backtrack to reconstruct the solution.
