🔄 What is Iteration?

Iteration means repeatedly executing a block of instructions until a particular condition becomes false.

📚 How It Works

  • Initialize the loop variable
  • Check the condition
  • Execute the loop body
  • Update the variable
  • Repeat until the condition is false

📈 Iteration Complexity

Time Complexity O(n)
Space Complexity O(1)
